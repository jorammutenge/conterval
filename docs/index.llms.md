How an engagement runs

## Small scope first, then build.

### Scope

Start from the decision the work should improve, check the data can support it, and agree what success looks like.

### Build

Deliver in short cycles against real data, so you see working output early and can change direction cheaply.

### Hand over

Finish with documented code, tests and a walkthrough, so your team owns the result.
